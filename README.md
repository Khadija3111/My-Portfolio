## 🛠️ Getting Started

### Prerequisites

- **Node.js** (v20 or later) – https://nodejs.org/
- **npm** (comes with Node.js) or **pnpm** / **yarn** if you prefer an alternative package manager.

### Installation

```bash
# Clone the repository (if you haven't already)
git clone https://github.com/your-username/my-portfolio.git
cd my-portfolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:3000`. The site will automatically reload as you edit files.

### Building for Production

```bash
npm run build   # Compile the app
npm start       # Start the production server
```

### Deployment

The site is configured for **Vercel** (the default platform for Next.js). After pushing to the `main` branch, Vercel will automatically build and deploy the app. You can also deploy manually using the Vercel CLI:

```bash
npm i -g vercel
vercel
```
